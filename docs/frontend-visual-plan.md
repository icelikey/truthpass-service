# 前端视觉与美工预案

## 视觉目标

页面需要让评委先看到“这瓶鱼油是否值得信任”，再看到“证据来自哪里、服务当前是否可用、消费者如何参与”。风格采用深海蓝作为可信底色，使用青绿色表示通过，琥珀色表示待复核，珊瑚红表示拒绝，避免金融产品式的高饱和涨跌视觉。

## 页面结构

### 1. 首页 / 批次搜索

- 顶部：真验 Logo、网络状态、演示标识 `DEMO / SYNTHETIC`；
- 中部：批次号输入和“让 Agent 验证”按钮；
- 下方：最近批次、服务可用率、公共反馈数量；
- 主视觉：一粒鱼油胶囊、冷链温度线和链上指纹的抽象组合。

### 2. 批次证据卡

- 左侧：产品图、批次、生产时间、来源等级；
- 中部：EPA+DHA、过氧化值、TOTOX 三个指标卡；
- 右侧：当前服务状态、验收结论、失败原因；
- 底部：原料 → 提炼 → 灌装 → 检测 → 冷链 → 消费者反馈时间轴；
- 每项证据显示“厂商自报 / 第三方 / 设备 / 消费者”标签。

### 3. 服务选择面板

用三张服务卡演示历史信誉和当前探测的差异。历史 96 分但离线的服务必须比在线且本次验收通过的服务更弱，帮助评委理解真验的核心价值。

### 4. 消费者共建面板

以授权开关、购买绑定、反馈标签和贡献积分构成最小交互。授权文案要明确“只读取本批次反馈所需数据”，不要出现医疗效果承诺。

## 视觉组件

| 组件 | 状态 | 文案示例 |
| --- | --- | --- |
| 验收徽章 | 通过/待复核/拒绝 | `已验收`、`需要复检`、`已拒绝` |
| 指标卡 | 正常/超标/缺失 | `EPA+DHA 78%`、`过氧化值 7.2` |
| 服务心跳 | 在线/降级/离线 | `当前在线 420ms` |
| 来源标签 | 四种证据来源 | `第三方报告`、`设备记录` |
| 链上指纹 | 已锚定/待锚定 | `证据哈希 0xb436…` |

## 实现约束

- 首屏不使用长段技术术语；
- 任何总分必须能点击展开到指标和证据；
- 拒绝状态不能只显示红色，要显示可操作原因；
- 所有模拟数据展示 `demo/synthetic`；
- 移动端优先保证证据卡和反馈表单可用；
- 图像只做氛围和识别，不代替报告或检测数据。

高保真方向图见仓库中的 `assets/fish-oil-evidence-dashboard.png`。它是视觉方向稿，最终页面应以真实接口返回的状态和文字为准。
