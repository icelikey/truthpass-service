## 运行

    npm run demo:fish-oil-e2e
    npm test
    npm run typecheck

主数据集：

- examples/fish-oil-order-to-delivery-demo.json
- 生产与实验室数据嵌套于 productionAndEvidence；
- 商品、订单、支付、库存、履约、运输和消费者数据位于 commerceFlow；
- anchorPlan 只生成离线摘要包，不代表已经提交 BOT Chain。

## 闭环顺序

    批次证据验收
      → 商品上架
      → 消费者下单
      → 模拟支付捕获
      → 库存扣减与拣货
      → 包装与批次复核
      → 模拟运输和温度记录
      → 交付签收
      → 消费者授权
      → 购买绑定
      → 一次性反馈
      → 服务信誉反馈
      → 离线链上锚定摘要

脚本会验证：

- 商品、订单、履约、运单是否指向同一成品批次；
- 支付是否绑定订单且金额/币种一致；
- 库存扣减是否等于订单数量；
- 包装批次是否匹配；
- 运输是否已交付、封签是否完整、冷链间隔是否在任务范围内；
- 消费者反馈是否绑定已授权的购买记录；
- 质量验收结果是否可生成服务信誉记录。

所有订单、支付、库存、物流、签收、消费者和链上数据均为模拟数据。当前 Verifier 的 accepted 只表示现有规则字段通过，不能解释为真实实验室认证、真实支付成功或实际链上交易。
