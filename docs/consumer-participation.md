# 消费者 Agent 参与规则

## 定位

消费者 Agent 是批次证据的协作者和公共信誉的反馈入口，不是未经资质授权的检测机构。它可以帮助消费者查看证据、记录购买、提交体验反馈和发起复检，但不能根据气味或个人感受宣称鱼油具有医疗功效。

## 最小授权

消费者按批次授权以下范围之一：`purchase`、`packaging`、`odor`、`storage`、`quality-feedback`。授权内容生成哈希；原始订单和个人信息留在链下，授权可撤销。

## 防刷分

- 反馈必须绑定已登记的购买证明哈希；
- 同一消费者对同一购买记录只能提交一次；
- 反馈绑定批次和证据哈希；
- 评分只能在 1 到 5；
- 异常反馈进入争议队列，不直接覆盖检测结论；
- 同一设备、地址和批次的大量重复反馈在后续版本进入风控分析。

## 权益

比赛版本使用贡献积分、复检优先权、检测服务额度和售后优先等权益。后续可以把“早期消费者成为共建者”扩展为合同化的收益分配，但必须另行设计法律主体、资金来源、退出和争议规则。
