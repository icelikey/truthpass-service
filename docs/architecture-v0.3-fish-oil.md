# 真验 v0.3：鱼油批次透明化战略架构

## 一句话

真验把“消费者想买一瓶可靠鱼油”转成一个由多个 Agent 协作完成的可验收任务：服务先证明自己当前可用，交付再接受确定性检查，消费者购买后的授权反馈成为下一次选择可以复用的公共信息。

## 为什么鱼油适合

鱼油的价值不依赖一个抽象品牌故事，而依赖可测量的成分和过程：EPA+DHA 含量、过氧化值、TOTOX、重金属报告、原料批次、灌装批次、仓储温度和运输冷链。消费者也能理解“含量不足、氧化、有腥味、冷链断过”这些痛点。

首版将“生产环节透明”收敛为生产、检测和交付证据的可验收摘要；真正的工厂设备接入是后续阶段，不能在 Demo 中假装已经完成。

## 生产方与消费者如何共同让良币变好

生产方提交批次和证据，检测服务提供签名报告，冷链服务提供温度摘要，真验负责探测与验收，消费者 Agent 在购买后提供包装、气味、保存和批次可查反馈。任何一方的记录都不能单独构成绝对真实；多源一致、可追溯和可撤销，才构成更高的公共可信度。

消费者获得贡献积分、复检优先权和服务额度等权益。早期共建者分润或股权是未来商业模型，必须在合规、合同和财务规则明确后再做，比赛 MVP 不实现。

## 关键架构原则

1. **规则优先**：自然语言交给 Agent，关键判定交给代码；
2. **证据分层**：厂商自报、第三方报告、设备记录、消费者反馈分级展示；
3. **链上最小化**：链上留下可复核指纹，原文和隐私留在链下；
4. **失败可见**：离线、批次错、签名错和指标不达标都要显示原因；
5. **可争议**：任何反馈都有撤销和复检入口，不把一次评分当成永久真理；
6. **可替换**：检测服务和模型通过适配器接入，不绑定单一供应商。

## 现场演示重点

先展示实验室 A 历史分高但当前返回错误批次，实验室 B 历史分高但离线，最后由实验室 C 完成有效签名和指标交付。然后消费者 Agent 绑定 FO-2026-001，授权最小反馈范围并提交一条反馈。评委看到的不是静态二维码，而是一次真实的服务选择、履约验收和信誉更新过程。
