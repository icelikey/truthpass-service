## 浏览器验收

已打开并检查：

```text
http://127.0.0.1:4173/?view=consumer&batch=FO-2026-001
http://127.0.0.1:4173/sites/fish-oil-demo/agent?batch=FO-2026-001
```

可见交互：

- 首页批次查询会带着 `batchId` 进入 Agent；
- 租户 Agent 首次进入自动执行当前批次查询；
- Agent 卡展示结论、依据、不确定和下一步；
- “回答依据”展示数据模式、来源和回退状态；
- “数据流过程”逐条滚动展示 API/SSE 事件、`traceId`、证据数量和批次；
- 生命周期 API 的后续事件不会覆盖完成态标题；
- `anchor_pending` 与“没有当前交易 receipt”同时可见；
- 钱包仍保持只读可查看，写入动作需要外部钱包确认。
