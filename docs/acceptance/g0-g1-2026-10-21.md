# TruthPass G0/G1 验收证据包（2026-10-21）

## 结论

G0 和 G1 已通过本地验收。页面、租户批次上下文和大米演示接口可以组成一条可复现的只读链路：

```text
平台首页 → 大米站点 → RC-2026-001 → Agent → 证据卡 → 钱包/企业/机构
```

当前仍不能宣称 G2/G3 完成：本地没有 `AGENT_API_KEY`，Agent 使用 `deterministic_fallback`；BOT Chain RPC 不可达，也没有本次会话的真实签名、广播和 receipt。

## G2/G3 阻塞

### G2：真实 DeepSeek

需要在本地或部署环境配置：

```text
AGENT_API_KEY
AGENT_BASE_URL=https://api.deepseek.com
AGENT_MODEL=deepseek-chat
```

放行证据必须包含 `provider=deepseek`、`modelAssisted=true`、`pipeline.deepseek.status=completed` 的真实 SSE 原文。

### G3：钱包和链

当前 `/api/chain/status` 显示：

```text
chainId: 677
rpcLive: false
anchored: false
replayVerified: true
sessionTransactions: 0
```

历史回放凭证不会被显示为当前交易。真实放行仍需外部钱包连接、Chain 677、用户签名、广播、receipt 回读和业务事件匹配。
