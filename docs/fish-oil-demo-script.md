# 鱼油 Demo 现场脚本

## 目标

在 3 到 5 分钟内让评委看到：真验没有因为服务有身份或历史高分就盲目信任，而是先探测、再调用、再验收，最后让消费者反馈进入公共信誉。

## 场景数据

- 商品：高浓度鱼油软胶囊；
- 批次：`FO-2026-001`；
- 标签声明 EPA+DHA：80%；
- 验收门槛：EPA+DHA ≥ 70%、过氧化值 ≤ 5、TOTOX ≤ 20、冷链中断 ≤ 6 小时；
- 证据来源：`demo/synthetic`。

## 操作顺序

1. 输入“帮我找一批证据完整、新鲜度合格的鱼油”；
2. 展示三个候选服务及历史分；
3. 点击探测：A 在线但能力结果异常，B 离线，C 健康；
4. 点击验收：展示 A 的批次错误、签名无效、含量和氧化指标失败；
5. 展示 C 的 EPA+DHA 78%、过氧化值 2.1、TOTOX 11、冷链中断 2 小时，状态为 `accepted`；
6. 展示证据哈希和待锚定事件；
7. 切换消费者视角，授权 `purchase + packaging + odor + storage + quality-feedback`；
8. 登记购买并提交“包装完好、无明显腥味、批次可查”；
9. 展示一次性反馈、贡献积分和公共信誉新增记录；
10. 说明：链上保证记录未被悄悄改写，真实性仍由检测、设备、复检和争议机制共同维护。

## 失败备用

现场网络不可用时使用仓库内的合成数据运行离线页面和录屏。讲解中明确“这是规则与交互 Demo，不是现实实验室报告”。
