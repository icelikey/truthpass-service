# TruthPass 中文前端文案基线 v1

## 品牌和首屏

```text
TruthPass
白牌商品证据基础设施
让每一批商品的证据都能被 Agent 复核
从生产、检测、物流到客服和售后，统一呈现可验证的批次信息。
```

主按钮：

```text
查看演示批次
打开企业证据工作台
```

辅助说明：

```text
当前演示：鱼油批次 FO-2026-001
DEMO / SYNTHETIC · 非真实商品认证
```

```

```

解释模板：

```text
这表示当前登记的证据状态，不等同于商品质量认证。
缺少证据只表示当前无法核实，不代表该项自动不合格。
你可以查看来源，或要求商家补充与本批次一致的材料。
```

```text

```
